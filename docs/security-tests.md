# Security tests

Where each case of the security plan is tested. Every test runs in `npm test` and in CI.

| Case                  | Tests (file: test)                                                                                                                                                                                                                                                                                                                                                                                                                                                                           |
| --------------------- | -------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------- |
| Altered signatures    | `apps/web/src/lib/identity/pades.test.ts`: a tampered signature value fails the signature check. `apps/web/src/lib/auth/session.test.ts`: reject a tampered payload. `packages/verifier/src/verify.test.ts`: fails the signature when the record was not signed by the anchored signer. `contracts/test/AttestationRegistry.ts`: rejects a signature from a key that is not the issuer signer.                                                                                               |
| Wrong wallet          | `apps/web/src/lib/auth/siwe.test.ts`: reject a signature from another account. `apps/web/src/lib/requests.test.ts`: validateRequest refuses a signature from another wallet. `apps/web/src/lib/identity/binding.test.ts`: only the bound wallet signature verifies. `apps/web/src/lib/issuer.test.ts`: the holder refuses a file for another wallet. `packages/vault/src/encryption.test.ts`: another recipient rejected.                                                                    |
| Unknown source        | `apps/web/src/lib/identity/pades.test.ts`: a signer outside the trust anchors fails the chain. `contracts/test/AttestationRegistry.ts`: rejects an unknown issuer. `packages/verifier/src/verify.test.ts`: fails provenance for a record from another registry, or when the anchor names another issuer. `apps/web/src/lib/status.test.ts`: imported and signature-verified items stay declared.                                                                                             |
| Corrupted data        | `packages/vault/src/encryption.test.ts`: modified ciphertext, tag or IV, and corrupted or truncated envelopes fail closed. `packages/vault/src/storage.test.ts`: malformed, oversized or cryptographically corrupted bytes, and disk corruption after a restart. `apps/web/src/lib/identity/pades.test.ts`: a PDF modified after signing fails integrity. `packages/verifier/src/verify.test.ts`: fails integrity when the shared value was changed.                                         |
| Replayed nonce        | `apps/web/src/lib/auth/nonces.test.ts`: a nonce can be consumed once, an unissued or expired one is refused. `contracts/test/AttestationRegistry.ts`: rejects a replay on the same contract, another contract or another chain. `packages/verifier/src/verify.test.ts`: refuses a stale or altered request. `packages/vault/src/sharing.test.ts`: replay fails closed.                                                                                                                       |
| Expired consent       | `apps/web/src/lib/requests.test.ts`: a pending request past its end date expires and cannot be answered. `packages/vault/src/sharing.test.ts`: expiry is checked during envelope creation and every delivery. `packages/vault/src/privacy.test.ts`: a missing, withdrawn or expired consent prevents inference. `apps/web/src/lib/auth/session.test.ts`: reject an expired session.                                                                                                          |
| Unauthorised access   | `apps/web/src/lib/request-access.test.ts`: only the signing wallet is the requester, a visitor never learns how a request ended. `apps/web/src/lib/vault/holders.test.ts`: registerKey refuses unknown holders and rebinding. `packages/vault/src/integrity.test.ts`: key removal gives FORBIDDEN. `contracts/test/AttestationRegistry.ts`: refuses a revocation by anyone else.                                                                                                             |
| Revocation            | `contracts/test/AttestationRegistry.ts`: lets the issuer admin or signer revoke, once. `packages/verifier/src/verify.test.ts`: reports a revoked attestation. `packages/vault/src/sharing.test.ts`: revoked consent fails closed, and a file-persisted revocation survives a restart.                                                                                                                                                                                                        |
| Leaks (network, logs) | `apps/web/src/lib/request-access.test.ts`: no server code writes to the console; a request view carries no decision, grant, share reference or key pins. `apps/web/src/lib/vault/http.test.ts`: never echoes an unexpected error. `packages/vault/src/storage.test.ts`: backend failures never expose internal paths. `packages/vault/src/privacy.test.ts`: model outputs and PDF jobs are purged. `packages/vault/src/extraction.test.ts`: prompt injection rejected before any model call. |
| Recovery after error  | `apps/web/src/lib/requests.test.ts`: a consent whose grant failed can be answered again. `packages/verifier/src/verify.test.ts`: lets the requester retry after the chain was unreachable. `packages/vault/src/extraction.test.ts`: temporary files purged after a callback failure. `packages/vault/src/storage.test.ts`: disk corruption detected after restarting the file adapter.                                                                                                       |
